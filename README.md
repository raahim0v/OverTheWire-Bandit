# OverTheWire Bandit – Linux & Cybersecurity Practice

## About the Project

This repository contains my practical work and learning experience from the OverTheWire Bandit wargame.

The purpose of this project was to improve my Linux command-line skills and understand basic cybersecurity concepts through hands-on challenges.

## Topics Covered

- Linux Command Line
- File Permissions and Ownership
- SSH and SSH Authentication
- File Searching and Text Processing
- Base64 and ROT13 Encoding
- File Compression and Archiving
- Nmap Port Scanning
- Netcat and OpenSSL
- SUID Permissions
- Restricted Shells

## Tools and Environment

- Kali Linux
- Linux Terminal
- SSH
- Nmap
- Netcat
- OpenSSL
